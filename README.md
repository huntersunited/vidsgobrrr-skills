# vidsgobrrr skills

Make short video ads with vidsgobrrr from your AI assistant: plan the ad, write the script, approve each step and its price, and get the finished video.

## Connect

1. Install this plugin in your AI assistant, or add the vidsgobrrr connector with this address: https://vidsgobrrr.com/mcp
2. Sign in with the email you use for vidsgobrrr. The sign-in screen asks which workspace to use.
3. You never type a password or key into the chat. Sign-in only happens on the vidsgobrrr sign-in page.

In Claude Code: `/plugin marketplace add huntersunited/vidsgobrrr-skills`, then install `vidsgobrrr`.

## Skills

- **make-ad**: Make a short video ad with vidsgobrrr from a goal: pick the play, write one concept and script, get the look and voice right, price and make a cheap preview, check it, then the HD video. Every paid step is priced first and needs the user's yes. Use when the user asks to make, create or start a video ad or a short video with vidsgobrrr.

Help: https://vidsgobrrr.com/guides

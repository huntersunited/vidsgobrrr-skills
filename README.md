# vidsgobrrr skills

Make short video ads with vidsgobrrr from your AI assistant: plan the ad, write the script, approve each step, and get the finished video.

## Connect

1. Install this plugin in your AI assistant, or add the vidsgobrrr connector with this address: https://vidsgobrrr.com/mcp
2. Sign in with the email you use for vidsgobrrr. The sign-in screen asks which workspace to use.
3. You never type a password or key into the chat. Sign-in only happens on the vidsgobrrr sign-in page.

In Claude Code: `/plugin marketplace add huntersunited/vidsgobrrr-skills`, then install `vidsgobrrr`.

## Skills

- **make-ad**: Make a short video ad with vidsgobrrr from a goal: pick the play, write one concept and script, get the look and voice right, price and make a cheap preview, check it, then the HD video. Every paid step is priced first and needs the user's yes. Use when the user asks to make, create or start a video ad or a short video with vidsgobrrr.
- **harvest-marketing-video-ideas**: Turn short-form ads the user has found working in public ad libraries, or on accounts they follow, into ideas scored for the user's product, and turn the best into ready vidsgobrrr briefs. Use when the user asks for ad ideas, opening lines, what's working, what competitors run, or "what should my next ad be". Nothing is spent by looking.
- **decode-reference**: Break down a short-form ad the user supplies (a link, a file, or screenshots) into its format, opening, beats, frame layout and a reusable formula, and say how much of it vidsgobrrr can make today. Never copies or makes the source. Use when the user shares an ad and asks how it works, why it works, or wants one like it.
- **clone-hook**: Rebuild the opening of an ad that works, using the user's own product, person, words and ask, as a new short vidsgobrrr video. Keeps how the opening works, never what it says or shows. Use after decode-reference or a saved idea, or when the user asks for "an opening like this one". Every paid step is priced first and needs the user's yes.
